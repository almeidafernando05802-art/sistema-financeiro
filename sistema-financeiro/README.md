# Sistema Financeiro (Node.js + Express + Supabase + Vercel)

Arquivos:
- server.js            -> todo o backend
- public/index.html    -> todo o frontend
- supabase/01_schema.sql         -> tabelas, RLS, triggers (rodar no SQL Editor)
- supabase/02_promover_admin.sql -> promove o administrador
- .env.example         -> nomes das variáveis (copie para .env e preencha)

Rodar local: npm install && npm run dev  ->  http://localhost:3000
